# ai-joke-03 entry

A one-liner about AI coding agents for the make.fun "Make the AI judge laugh"
competition: `main.py` writes one fixed joke to `/output/entry.txt`. The joke
is a true observation from daily work beside a coding agent — it hallucinates
a library that doesn't exist, writes the documentation for it, and then cites
its own documentation as proof — told in a single tight line with the
punchline in the agent's own words.
